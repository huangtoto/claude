# 早餐飲料提醒系統

## 問題描述
- 公司每天供應早餐，但飲料供應不固定
- 餐廳離座位遠，希望出發前就知道要不要帶杯子
- 早上電腦未開機，查看菜單不便
- 希望每天早上自動收到 LINE 提醒

## 解決方案

### 方案一：Python + LINE Notify + 定時執行（推薦）

**優點：**
- 實作簡單，維護容易
- LINE Notify 免費且易用
- 可加入 OCR 自動判斷飲料

**缺點：**
- 需要在公司內網執行（因為菜單 URL 僅限內網）

**所需環境：**
- 公司內網的電腦/樹莓派（或任何可 24 小時運行的設備）
- Python 3.7+
- LINE Notify Token

### 方案二：手動更新 + LINE Bot

**優點：**
- 不需要 OCR，人工確認更準確
- 可由行政人員或志願者更新

**缺點：**
- 需要人工介入

### 方案三：簡化方案

**直接解決問題的思路：**
1. **永遠帶杯子** - 反正杯子很輕，帶了沒飲料也無妨
2. **保持兩個杯子** - 座位一個、背包一個
3. **使用折疊杯** - 輕便可收納的矽膠折疊杯

## 推薦實作：方案一

### 架構
```
內網設備 (樹莓派/舊電腦)
  ├─ 定時任務 (crontab: 每天 7:30)
  ├─ 下載菜單圖片
  ├─ OCR 識別 / 關鍵字檢測
  └─ LINE Notify 發送通知
```

### 實作步驟

1. **申請 LINE Notify Token**
   - 前往 https://notify-bot.line.me/
   - 登入後發行個人存取權杖
   - 選擇要接收通知的聊天室

2. **設定執行環境**
   - 在公司內網找一台可持續運行的設備
   - 安裝 Python 和必要套件

3. **設定定時執行**
   - 使用 crontab 或 Windows 工作排程器
   - 建議時間：每天早上 7:00-7:30

4. **測試與調整**
   - 測試圖片下載
   - 測試 LINE 通知
   - 調整 OCR 準確度

## 進階功能建議

1. **智能提醒**
   - 前一天晚上提醒（可以提前準備）
   - 若連續多天有/無飲料，可調整通知頻率

2. **錯誤處理**
   - 網路失敗時發送預設提醒
   - 圖片無法下載時通知

3. **統計功能**
   - 記錄飲料供應頻率
   - 預測模式（例如週一通常有飲料）
